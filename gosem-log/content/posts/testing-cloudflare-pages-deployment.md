This is a test article for the new Cloudflare Pages deployment.

If you can read this article at [Gosem Log](https://gosem-blog.pages.dev/), the automatic publishing workflow is working correctly:

1. The article was committed and pushed to the `master` branch.
2. Cloudflare Pages detected the change.
3. Hugo built the website.
4. Cloudflare published the generated site.

The blog is now deployed directly from the source repository without using GitHub Pages.
